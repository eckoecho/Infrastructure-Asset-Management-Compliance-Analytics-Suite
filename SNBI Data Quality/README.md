## Overview

An analytical dashboard created to identify and prioritize federal submission errors by geographic region, data field, and severity.

## Business Problem

Federal infrastructure reporting contains hundreds of required data fields. Missing or invalid values can prevent successful submission and create significant manual review efforts.

Users needed an efficient method to determine:

- Which districts had the highest error rates
- Which data elements caused the most problems
- Which records required immediate attention

## Solution

Developed an interactive Tableau dashboard combining geographic visualization with error analytics.

The dashboard enables users to:

- Visualize error distribution across districts
- Prioritize high-volume error fields
- Filter by error level
- Search specific bridge identifiers
- Review detailed record-level validation failures

## Key Features

- Choropleth map
- Ranked error field visualization
- Dynamic filtering
- Detailed error table
- Interactive cross-filtering
- Error severity analysis

## Business Impact

Reduced the effort required to identify submission issues by enabling users to immediately isolate problematic districts, prioritize corrective actions, and focus on the highest-impact data quality issues before federal submission.
