# Infrastructure Scour Documentation Dashboard

## Overview

A GIS-enabled dashboard designed to identify infrastructure assets with missing or incomplete scour evaluation documentation, allowing engineering teams to prioritize corrections and maintain regulatory compliance.

---

## Business Problem

Scour evaluations are a critical component of infrastructure safety assessments. Missing evaluations, incomplete Plans of Action (POAs), or absent historical documentation can result in compliance deficiencies and increase the effort required during reporting cycles.

Engineering staff previously relied on multiple reports to determine which structures required follow-up, making statewide monitoring both time-consuming and difficult.

---

## Solution

Developed an interactive Tableau dashboard that centralizes scour documentation deficiencies into a single operational workspace.

Users can:

- Identify structures missing scour evaluations
- Locate assets missing Plans of Action (POAs)
- Review historical documentation deficiencies
- Filter deficiencies by district
- Visualize affected assets geographically
- Drill directly into individual structure records

---

## Key Features

- Interactive GIS map displaying deficient structures
- District-level filtering
- Multiple deficiency categories
  - Missing Scour Evaluations
  - Missing Plans of Action
  - Missing Historical Documentation
- Detailed bridge-level information
- Direct navigation to individual asset records
- Export functionality for district follow-up
