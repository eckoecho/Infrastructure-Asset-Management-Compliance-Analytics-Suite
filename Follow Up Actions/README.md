# Follow-Up Actions Dashboard

## Overview

A GIS-enabled operational dashboard developed to monitor infrastructure follow-up actions, repair priorities, and maintenance progress across an entire transportation network.

---

## Business Problem

Infrastructure follow-up actions were distributed across thousands of assets and numerous districts.

Decision makers needed visibility into:

* Outstanding repairs
* Geographic concentrations of issues
* Maintenance priorities
* Funding categories
* Completion status

Without visualization, identifying statewide trends required extensive manual reporting.

---

## Solution

Designed a GIS-centric dashboard integrating mapping, summary metrics, and operational reporting into a single interactive interface.

Users can:

* Explore repairs geographically
* Filter by county
* Filter by district
* Review repair priorities
* Monitor overdue actions
* Analyze funding sources
* Drill into individual follow-up records

---

## Key Features

* Interactive GIS map
* Dynamic county search
* KPI cards
* District comparison charts
* Priority-level visualization
* Drill-down detail table
* Multi-filter interactions

Provided a centralized operational view of follow-up actions, enabling users to identify geographic trends, prioritize maintenance activities, and monitor progress toward completing infrastructure repairs.
